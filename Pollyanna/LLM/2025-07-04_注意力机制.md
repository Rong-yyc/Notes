# 注意力机制

## model architecture模型结构

<img src="images\image-20250704155038928.png" alt="image-20250704155038928" style="zoom:50%;" />

Transform依然采用编码器-解码器的结构，但是编码器和解码器均使用==堆叠的自注意力和逐点全连接层==。

> 堆叠(Stacked)：指的是将多个相同类型的层按顺序叠加在一起的结构设计。每一层以上一层的输出作为输入，逐步深化对数据的理解，并且增强模型对长距离依赖关系的建模能力。

> 自注意力（Self-Attention）：是一种注意力机制，它允许模型在处理序列数据时，<u>计算序列中不同位置元素之间的相关性</u>，从而动态地调整对每个元素的关注程度，捕捉序列内部的复杂依赖关系。
>
> > 如何计算的序列中不同位置元素之间的相关性：在自注意力机制中，查询（Query）、键（Key）和值（Value）都来自同一输入序列。通过计算 Query 与所有 Key 的相似度得分（如通过点积计算），并经过 Softmax 归一化得到注意力权重，再用这些权重对 Value 进行加权求和，得到当前位置的输出表示 。

>  逐点全连接层：是一种全连接前馈网络，在编码器和解码器的每个层中，与注意力子层配合使用。它对<u>序列中的每个位置</u>进行单独且相同的处理，用于对注意力机制输出的特征进行进一步转换和映射。如FFN
>
> > 序列中的每个位置：举个例子来说，输入一个文本序列“我爱吃饭”，经过分词器拆分成“我“ ”爱“ ”吃” “饭” 其中“吃”这个就是序列中的一个位置。



------

图中左边的部分就是编码器，它由以下几个部分组成（以中翻英机器翻译任务为例）：

**Inputs（输入）：**中文文本序列

**Input Embedding（词嵌入阶段）**：对输入的中文文本序列，先通过分词器（像结巴分词、哈工大 LTP 等工具，针对中文语义和词汇特点，把文本拆成一个个有意义的词或子词，比如 “机器学习” 拆成 “机器”“学习” ），得到分词后的离散词汇序列。接着，把这些离散词汇映射成==词嵌入矩阵==，每个词对应一个固定维度（比如图中可能隐含`d_model`维度，常见如 512 ）的连续向量。这一步是为了将文本的语义信息转化为模型能理解、计算的数值形式，让词汇间语义关联（如 “机器” 和 “学习” 因常一起出现，向量会有一定相关性 ）能被后续层捕捉。



**Positional Encoding（位置编码阶段）**：因为词嵌入只体现词汇本身语义，没包含文本中词的位置信息，所以要加上==位置编码==。位置编码会依据词在序列里的位置，用特定数学方式（如论文里的正弦、余弦函数组合 ）生成与词嵌入同维度的位置向量，再和词嵌入矩阵==逐元素相加==（图中⊕ 操作 ），让模型能区分 “我喜欢他” 和 “他喜欢我” 这类因顺序不同语义不同的文本，补充序列的位置信息 。



**Multi-Head Attention（多头注意力阶段）**：经过位置编码的向量进入多头注意力层。这里，当前层输入会分别线性变换成多组（比如 8 组，对应多头 ）Query（查询）、Key（键）、Value（值）。下面Attention部分会详细解释。



**Add & Norm（残差连接与层归一化阶段）**：多头注意力的输出，会和进入该层之前的输入（即位置编码后的向量，图中箭头回连的部分 ）做残差连接（Add 操作，逐元素相加 ），这能缓解深层网络训练时梯度消失问题，让信息更顺畅传递，也保留初始输入的部分特征 。

* add：又名残差连接，把层的输入和输出做**逐元素相加**，公式可简化为 Output=Input+Layer(Input)（Layer 代表当前子层，如多头注意力、前馈网络）。它的作用是保留原始信息，缓解梯度消失

* Norm（层归一化）：通常用 Layer Normalization，计算方式是对单个样本的特征维度做归一化，先算该样本特征的均值和方差，再通过公式

$$
Norm(x)=\gamma\dfrac{x-\mu}{\sigma+\epsilon}+\beta,其中\gamma和\beta是可学习参数
$$

目的是让各维度分布更稳定。因为深度神经网络中，随着网络层数的增加，每层输入数据的分布会发生变化，这种现象被称为内部协变量转移（Internal Covariate Shift）。这种数据分布的变化使得模型训练变得困难，因为神经网络需要不断适应新的分布，这会导致训练过程中梯度更新不稳定，模型收敛速度变慢。



**Feed Forward（前馈网络阶段）：**归一化后的结果进入前馈网络层，它包含两个线性变换（全连接层 ）和中间的 ReLU 激活函数，公式一般是：
$$
FFN(x)=max(0,xW_{1}+b_{1})W_{2}+b_{2}
$$

操作是：对序列中每个位置的特征向量，先升维、ReLU 激活增加非线性，再降维，进一步转换、提炼特征，让模型学习更复杂的语义模式，比如挖掘 “机器学习” 和 “很有趣” 之间的语义关联，理解整句话表达对机器学习的积极态度 

------

图中右边的部分就是编码器，它和编码器的构造基本上相同，它由以下几个部分组成（以中翻英机器翻译任务为例）：

**Outputs (shifted right) & Output Embedding（输出嵌入阶段）**：

* 序列移位（shifted right）：为了让模型在生成序列时具有自回归特性（即生成第 i 个位置时，只能看到前 \(i - 1\) 个位置内容 ），输入到解码器的序列会**==向右移位填充==**（比如在开头补特殊占位符，如 `<sos>` 之类的起始标记 ）。这样处理后，序列变成类似 “<sos> 这是生成的” （假设原序列是 “这是生成的文本” ），保证模型生成每个位置时，仅依赖之前生成的内容。
* 分词与词嵌入，与编码器部分一样，得到词嵌入矩阵$X$。

**Positional Encoding（位置编码阶段）**：同上

**Masked Multi-Head Attention（掩码多头注意力阶段）**：掩码操作是为了**在注意力计算环节，强行限制模型的 “视野”** —— 让每个位置的 Query 只能关注**前序位置**（或合法的已生成位置 ），彻底杜绝 “偷看未来位置” 的可能。

​		具体实现逻辑：

​		通过前面的步骤，我们已经有了输入的矩阵$X$，维度`4×512`和相似度矩阵$ S_1 $，维度`4x512`

​		 Masked Multi - Head Attention 层中，计算注意力权重时，会构造一个**下三角掩码矩阵**M，维度`4x4`如下：

1. $$
   M = \begin{pmatrix}
   0 &-\infty & -\infty &-\infty \\
   0 & 0 &-\infty & -\infty \\
   0& 0 & 0 & -\infty \\
   0 & 0 & 0 & 0
   \end{pmatrix}
   $$

   矩阵中，`0` 表示 “允许关注”，`-∞` 表示 “禁止关注”

   第$ i$ 行第 $j $列：若$j>i$ ，则填 `-∞`（禁止当前位置关注后面的位置 ）

2. 将掩码 M 加到相似度矩阵$ S_1 $上$S_1^,= S_1 + M$

3. 对 $S_1^,$每行做 Softmax，得到注意力权重矩阵 $A_1$（维度 `4×4` ）：$A_1 = \text{Softmax}(S_1')$

4. 由于掩码的存在，第 i 行中$j>i$  的位置权重会趋近于 0，模型无法关注这些位置。

5. 用权重矩阵 $A_1$ 对 $V_1$ 加权求和，得到第 1 个头的输出 $O_1$（维度 `4×64` ）：$O_1 = A_1 \cdot V_1$

6. 重复上述步骤，计算 8 个 “头” 的输出 $O_1$, $O_2$, ..., $O_8$（每个维度 `4×64` ）。

7. 将 8 个头的输出**拼接**起来，得到维度 `4×512` 的矩阵：$O_{\text{concat}} = [O_1 \mid O_2 \mid \dots \mid O_8]$

8. 最后，通过线性变换 $W_O$得到 `Masked Multi-Head Attention` 的最终输出 O（维度 `4×512` ）：$O = O_{\text{concat}} \cdot W_O$

   

**Multi-Head Attention（多头注意力阶段，跨编码器 - 解码器交互 ）**:这一层是解码器与编码器交互的关键（图中左侧箭头，假设连接到编码器输出 ）。此时，Query 来自解码器上一层的输出，而 Key 和 Value 来自**编码器的最终输出**（编码器处理输入序列后得到的全局语义表示 ）。通过多头注意力机制，解码器每个位置可以关注编码器输入序列的所有位置（比如机器翻译中，生成中文译文的每个词时，关注英文原文的对应语义片段 ），建立源序列和目标序列之间的语义对齐，让生成的内容更贴合输入语义。



## Attention

### Scaled Dot-Product Attention缩放点击注意力

<img src="images\image-20250704154713020.png" alt="image-20250704154713020" style="zoom:50%;" />

这是基础的注意力机制工作图，工作原理如下：

###### 输入：Q（查询）、K（键）、V（值）

- **作用**：Q 代表 “当前要关注什么”，K 代表 “提供了什么信息”，V 代表 “实际要提取的内容”。
- 文本对应：输入是维度 $d_k$的 queries（Q）、keys（K），和维度$d_v$的 values（V）。

###### 第一步MatMul（矩阵乘法）

- **功能**：计算 **Q 和 K 的相似度**（点积）。
- 把每个 query 和所有 key 做内积，得到 “原始相似度分数”。
- 数学表达：矩阵形式为 $QK^T$，结果是一个矩阵，每个元素表示某 query 和某 key 的关联程度。

###### Scale（缩放）

- **功能**：避免 softmax 梯度消失。
- 数学表达： $\frac{QK^T}{\sqrt(dk)}$
- 关键逻辑：当 $d_k$ 很大时，点积结果会 “数值过大”，导致 softmax 输出趋近于 one-hot（梯度几乎为 0 ）。缩放后，数值更合理，梯度更稳定。

###### Mask（可选）：Mask (opt.)

- **功能**：限制注意力范围（比如 decoder 里 “不能看未来 token”）。

###### SoftMax：归一化权重

###### 第二步 MatMul（矩阵乘法）：权重 × V

- **功能**：用 softmax 得到的权重，对 V 做 **加权求和**。
- 数学表达：$Attention (Q, K, V) = softmax ( \frac{QK^T}{\sqrt(dk)})V$ → 权重矩阵与 V 相乘，输出最终的注意力结果（融合了关键信息的特征）。



### Multi-Head Attention多头注意力

多头注意力就是缩放点击注意力一个一个链接起来的，可以看到在输入QKV之后加了一个linear线性层。这个线性层是进行降维作用。

## Q&A：

1.为什么进行了序列移位（shifted right）还要进行掩码操作

​		在 Transformer 解码器中，**序列移位（shifted right）** 和 **掩码操作（Mask）** 是两个不同维度的设计，共同保障模型的自回归（Auto - Regressive）特性，二者缺一不可，具体原因从它们的作用和解决的问题来看：

​		序列移位是为了让解码器在==训练阶段==，模拟 “自回归生成” 的流程 ——生成第 $i$ 个位置的词时，理论上只能依赖前 $i - 1$个位置的内容。局限性是序列移位只是物理上调整了输入序列的呈现形式，但模型内部的注意力机制在计算时，仍然可以 “看到” 整个输入序列的所有位置（包括当前位置及之后的位置 ）,掩码操作就是在注意力机制在计算时，限制模型的视野。

​	总的来说，序列移位是 “表面调整输入形式” ，掩码操作是 “底层限制注意力视野” 



2.为什么Query 来自解码器上一层的输出，而 Key 和 Value 来自编码器的最终输出。而不是Query 来自编码器呢

​		由模型的任务目标和自回归生成逻辑决定的，核心是为了实现 目标序列生成时，动态对齐并利用源序列语义。

* 编码器（Encoder）：处理**源序列**（如英文原文 ），提取全局语义表示（Key、Value ），涵盖源序列所有位置的信息。
* 解码器（Decoder）：生成**目标序列**（如中文译文 ），需基于源序列语义，**自回归地逐词生成**（生成第 i 个词时，依赖前 \(i-1\) 个词 ）。



3.KV缓存技术

​		定义：KV 缓存是一种在==推理阶段==，用于存储和复用 Transformer 解码器中多头注意力机制里的键（Key）和值（Value）向量的技术。在传统的 Transformer 推理过程中，每次生成一个新的 token 时，都需要重新计算注意力，而 KV 缓存则通过缓存之前计算得到的 Key 和 Value，避免了重复计算，从而提升推理效率。

* **初始化**：在推理开始时，KV 缓存为空。当处理输入序列的第一个 token `1x64` 时，正常计算其对应的 Key `1x64`和 Value` 1x64`向量，并将这些向量存储到 KV 缓存中。例如，在一个文本生成任务中，输入起始标记 `<sos>`，通过线性变换等操作得到对应的 Key 和 Value，并保存在缓存里。
* **后续计算**：在生成下一个 token 时，对于已经处理过的位置，不再重新计算其 Key 和 Value，而是直接从 KV 缓存中读取。只计算当前新位置对应的 Key 和 Value，并将新的 Key 和 Value 添加到缓存中。比如在生成第二个token时，计算第二个词的 Key 和 Value，更新缓存，此时我们就得到的KV缓存大小是`2x64`。随着推理的进行，缓存不断积累之前位置的 Key 和 Value 信息。
* **注意力计算**：在计算注意力权重时，使用缓存中的 Key 和 Value 与当前位置的 Query 进行计算。例如，当生成第三个词时，用第三个词的 Query 与缓存中存储的前两个词的 Key 计算相似度，得到注意力权重，再用这些权重对缓存中前两个词的 Value 以及当前第三个词新计算出的 Value 进行加权求和，从而得到当前位置的输出表示。

> 注意：由于是推理阶段，权重参数矩阵不会变
