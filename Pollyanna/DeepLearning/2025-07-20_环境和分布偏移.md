# 0.引言

我们现在讨论，模型的输入数据从哪里来，以及我们如何处理模型的输出。

第一个问题，我们训练出了一个模型，用和训练数据同分布的测试集测试，模型表现得非常好。但是一旦输入的数据分布不一样，那么模型就会失败。

第二个问题，机器学习的许多应用中都存在类似的问题， 通过将基于模型的决策引入环境，我们可能会破坏模型。例如， 假设我们训练了一个贷款申请人违约风险模型，用来预测谁将偿还贷款或违约。 这个模型发现申请人的鞋子与违约风险相关（穿牛津鞋申请人会偿还，穿运动鞋申请人会违约）。 此后，这个模型可能倾向于向所有穿着牛津鞋的申请人发放贷款，并拒绝所有穿着运动鞋的申请人。这种情况可能会带来灾难性的后果。 首先，一旦模型开始根据鞋类做出决定，顾客就会理解并改变他们的行为。 不久，所有的申请者都会穿牛津鞋，而信用度却没有相应的提高。 

# 1.分布偏移的类型

首先我们考虑数据分布可能发生变化的各种方式，以及为挽救模型可能采取的措施。

$P(x)$---特征的边缘分布，简单来说就是输入的分布

$P(y)$---标签边缘分布，简单来说就是标签的分布

$P(y \mid \mathbf{x})$---标签函数，条件分布

$P(x \mid \mathbf{y})$---类别条件分布

## 1.1协变量偏移

在不同分布偏移中，协变量偏移可能是最为广泛研究的。协变量偏移指的是输入的分布可能随时间而改变，但标签函数（即条件分布$P(y \mid \mathbf{x})$）没有改变。

举个例子描述这种情况就是训练集由真实照片组成，而测试集只包含卡通图片。

## 1.2 标签偏移

标签偏移（label shift）描述了与协变量偏移相反的问题。它指的 我们假设标签边缘概率$P(y)$可以改变，但是类别条件分布$P(\mathbf{x} \mid y)$在不同的领域之间保持不变。当我们认为$y$导致$\mathbf{x}$时，标签偏移是一个合理的假设。

举个例子描述这种情况，标签偏移的核心是两个 “变” 与 “不变”：

* **不变的**：类别条件分布$P(\mathbf{x} \mid y)$—— 即 “给定标签y时，特征$\mathbf{x}$的分布” 在训练（源领域）和测试（目标领域）中保持一致。
* **变化的**：标签的边缘分布$P(y)$—— 即 “不同标签y出现的比例” 在两个领域中可以不同。

这个假设的合理性来自 “因果关系”：当我们认为 “标签y是因，特征x是果。y导致x时，标签偏移更自然。

比如例子中 “疾病y导致症状x”：

* 无论疾病的流行率$P(y)$怎么变（比如流感在冬季更常见），“流感（\(y=\)流感）会引起发烧、咳嗽（\(\mathbf{x}\)的特定分布）” 这个规律（\(P(\mathbf{x} \mid y=\)流感)）是不变的；
* 变化的只是 “流感、感冒、肺炎等疾病的整体比例”（\(P(y)\)）。

## 1.3概念偏移

当标签的定义发生变化时，就会出现这种问题。



举一个例子来辨析上述的三个概念，

比如，$y=猫$这个标签，若原本定义是 “有毛、会喵喵叫的动物”，后来变成 “只要有毛的动物都算猫”，这就是概念偏移 ——“猫” 这个标签的含义变了。

而之前的标签偏移、协变量偏移中，标签的定义是**不变的**：

* 标签偏移：只是 “猫出现的比例” 变了（比如训练时猫占 30%，测试时占 70%），但 “什么是猫” 的定义不变；
* 协变量偏移：只是 “猫的特征分布” 变了（比如训练时猫多是白猫，测试时多是黑猫），但 “猫” 的定义还是 “有毛、会喵喵叫的动物”。

# 2.分布偏移纠正

正如我们所讨论的，在许多情况下训练和测试分布$P(x,y)$是不同的。 

在一些情况下，我们很幸运，不管协变量、标签或概念如何发生偏移，模型都能正常工作。
在另一些情况下，我们可以通过运用策略来应对这种偏移，从而做得更好。

2.1经验风险与实际风险

经验风险本质是 训练数据上的平均错误，但我们真正关心的不是模型在训练数据上表现多好，而是它在未来的新数据 （测试数据）上表现如何。

统计学家用 “真实风险” 来描述这个目标 —— 也就是模型在**所有可能数据**（来自真实分布）上的平均错误。但现实中我们不可能拿到所有数据，因此，机器学习的策略是**用 “经验风险” 近似 “真实风险”**：通过最小化训练数据上的平均错误（经验风险），来逼近最小化真实世界的平均错误（真实风险）。

介绍这个是为了引出机器学习的目标：最小化测试数据集的平均损失

2.2协变量偏移纠正

先看一个例子，我们要做一个区分猫狗图片的模型，训练数据是白天拍的，测试数据是晚上拍的，因此出现了协变量偏移的问题。

我们怎么做能够纠正这种偏差呢？答案是提高训练数据中背景比较暗，更接近夜晚的图片的权重。

具体来说（其中一种做法），我们可以先把训练数据和测试数据放在一起作为一个整体来训练出一个逻辑回归分类器。通过这个分类器我们可以计算出训练样本的权重，将这个权重引入训练时的平均损失函数中，大家又称这个函数为加权经验风险函数。于是，我们的目标就变成了在训练的过程中最小化加权经验风险函数。同时，通过这种方式去更新模型参数，模型就会更关心哪些接近目标样本的训练样本的特征。我们就到达了目的。

> 在这里我还想补充一次，关于二分类逻辑回归的输出。
>
> 二分类的标签是`Y=0`和`Y=1`。那么二分类逻辑回归的输出就是x属于`Y=1`类的概率$p(Y=1|x)$。当然了，多分类逻辑回归的输出是$p(Y=i|x)$

2.3标签偏移纠正

还是先看一个例子，我们要做猫狗图片分类任务，训练数据中猫狗占比3：7，测试数据猫狗占比6：4。那么我们需要纠正训练数据的占比 。我们怎么做能够纠正这种偏差呢？答案是提高训练数据中猫的权重。

2.4概念偏移纠正

概念偏移很难用原则性的方式解决。例如，在一个问题突然从“区分猫和狗”偏移为“区分白色和黑色动物”的情况下，除了从零开始收集新标签和训练，别无妙方。但幸运的是，通常情况下，概念的变化总是缓慢的。

3.学习问题的分类法

3.1批量学习

一次性学习大量的数据，得到模型

3.2在线学习

与 “批量学习” 一次性接收所有数据（如一次性获取大量历史样本，集中训练模型）不同，在线学习是**逐个处理数据样本**。

整个过程是一个 “观测 - 预测 - 反馈 - 改进” 的循环，具体步骤如下：

1. **先观测输入特征\(\mathbf{x}_i\)**：例如，今天看到股票的各种实时数据（\(\mathbf{x}_i\)）。
2. **基于当前模型做出预测\(f(\mathbf{x}_i)\)**：根据这些数据，用现有模型预测明天的股价（\(f(\mathbf{x}_i)\)）。
3. **获取真实结果\(y_i\)并评估**：等到明天结束，才能知道实际股价（\(y_i\)），此时可以计算预测的误差（损失）或收益（奖励）。
4. **根据反馈改进模型**：用这次的预测结果与真实结果的差异（损失或奖励），更新模型参数，让模型在下一次预测中更准确。

这个循环会不断重复，每处理一个新样本，模型就迭代优化一次。
