# 0.引言

在[模型选择、过拟合和欠拟合](./2025-07-18_模型选择、过拟合和欠拟合.md)一节我们描述了过拟合的问题。正则化是用来解决过拟合的一种技术。 假设我们已经拥有尽可能多的高质量数据，我们便可以将重点放在正则化技术上。

# 1.范数与权重衰减

上面说了参数取值的范围以及参数的数量都可能影响模型泛化，导致过拟合。那么在训练模型过程中，我们要保证权重向量比较小，最常用方法是将权重范数作为惩罚项加到最小化损失的问题中。然后我们还引入一个正则化常数$\lambda$来控制惩罚的力度。具体操作如下，

我们已经有一个损失函数：$$L(\mathbf{w}, b) = \frac{1}{n}\sum_{i=1}^n \frac{1}{2}\left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)^2.$$

回想一下，$\mathbf{x}^{(i)}$是样本$i$的特征，$y^{(i)}$是样本$i$的标签，$(\mathbf{w}, b)$是权重和偏置参数。为了惩罚权重向量的大小，我们必须以某种方式在损失函数中添加$\| \mathbf{w} \|^2$，但是模型应该如何平衡这个新的额外惩罚的损失？

实际上，我们通过*正则化常数*$\lambda$来描述这种权衡，这是一个非负超参数，我们使用验证数据拟合：

$$L(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2,$$

* 对于$\lambda = 0$，我们恢复了原来的损失函数。
* 对于$\lambda > 0$，我们限制$\| \mathbf{w} \|$的大小。

总结，在训练参数化机器学习模型时，权重衰减是一种正则化技术，通常称为$L_2$正则化。$L_2$正则化就是在损失函数上加上一个正则化常量$\lambda$乘上权重范数$\| \mathbf{w} \|^2$

> 我们已经描述了$L_2$范数和$L_1$范数。参考[范数](2025-07-15_线性代数.md)

## Q&A

1.为什么我们首先使用$L_2$范数，而不是$L_1$范数？

$L_2$正则化线性模型构成经典的*岭回归*（ridge regression）算法，$L_1$正则化线性回归是统计学中类似的基本模型，通常被称为*套索回归*（lasso regression）。
使用$L_2$范数的一个原因是它对权重向量的大分量施加了巨大的惩罚。这使得我们的学习算法偏向于在大量特征上均匀分布权重的模型。

在实践中，这可能使它们对单个变量中的观测误差更为稳定。相比之下，$L_1$惩罚会导致模型将权重集中在一小部分特征上，而将其他权重清除为零。这称为*特征选择*（feature selection），这可能是其他场景下需要的。

# 2.暂退法Dropout

这是另一种解决过拟合的方法。

重新审视过拟合，当样本的特征很多而样本不足时，模型往往会过拟合。简单来说，相比简单的线性模型，深度网络学习到的特征更多，就算有足够多的样本也可能会发生过拟合。那么有一种方法就是在训练过程中随机丢弃一些神经元。

具体的作法就是在训练的时候，将dropout应用于每个隐藏层的输出（在激活函数之后）， 并且可以为每一层分别设置暂退概率： 常见的技巧是在靠近输入层的地方设置较低的暂退概率。 

```python
net = nn.Sequential(nn.Flatten(),
        nn.Linear(784, 256),
        nn.ReLU(),
        # 在第一个全连接层之后添加一个dropout层
        nn.Dropout(dropout1),
        nn.Linear(256, 256),
        nn.ReLU(),
        # 在第二个全连接层之后添加一个dropout层
        nn.Dropout(dropout2),
        nn.Linear(256, 10))

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)

net.apply(init_weights);
```

需要注意的是，只在训练阶段用到了dropout，推理阶段没有用到。如果训练时的期望和测试时不一致，就会导致输出分布偏移，影响模型表现。

这就涉及到了dropout核心思想：为了保证在**训练阶段和推理阶段输出的分布一致** ，Dropout 在实现时会对保留下来的神经元进行**缩放（scale）** 。

缩放的具体公式如下，
$$
\begin{aligned}
h' =
\begin{cases}
    0 & \text{ 概率为 } p \\
    \frac{h}{1-p} & \text{ 其他情况}
\end{cases}
\end{aligned}
$$
意思是：

* 每个激活值 *h* 以概率$ p $被设为 0（即“丢弃”）；
* 以概率 1−$p$ 保留，但要放大 1−$p$倍。

这样做的目的是让：

$E[h]=h$

也就是说，**期望值保持不变** 。

举一个例子，对一个神经元来说，假设输出`h=2`有概率20%为`0`，概率80%为`2/0.8=2.5`,

## Q&A

1.为什么在测试时通常不使用暂退法？

Dropout 是一种**训练时使用的正则化技术** ，其目的是：

* 防止神经元之间的“过度依赖”；
* 提高模型的泛化能力；
* 模拟训练多个子网络的集成学习效果。

但在**测试阶段** ，我们不再需要“随机丢弃神经元”，原因如下：

* 测试需要稳定性和一致性

  测试时的目标是**对每个输入给出一个稳定、可重复的预测结果** ；

  如果在测试时也使用 Dropout，会导致输出具有随机性（每次预测可能不同），这在实际应用中是不可接受的。

* Dropout 在训练时已经通过缩放保留了期望值

  如你之前理解的，Dropout 在训练时会对保留的神经元放大 1−*p*1 倍，使得其期望值不变；

  因此，在测试时，我们只需**保留所有神经元并取消缩放** ，就可以得到与训练时期望一致的输出。

* 测试时不需要模拟“子网络”

  Dropout 的一个理论解释是：它在训练时随机创建了大量“子网络”，这些子网络共享权重；

  在测试时，我们希望使用一个**综合了所有子网络平均行为的完整网络** ；

  所以我们保留所有神经元，而不进行随机丢弃。

  

2.比较使用暂退法和权重衰减的效果。如果同时使用暂退法和权重衰减，会发生什么情况？结果是累加的吗？收益是否减少（或者说更糟）？它们互相抵消了吗？

他们可以使用，而且通常会带来更好的泛化性能。它们并不是互相抵消的关系，而是从**不同角度** 进行正则化。但是在使用的过程中要注意调参。



3.如果我们将暂退法应用到权重矩阵的各个权重，而不是激活值，会发生什么？

将 Dropout 应用到权重矩阵上（Weight Dropout）是一种有效的正则化方式，它从结构层面改变模型，可以与标准 Dropout 结合使用，提升模型泛化能力，但实现上更复杂，需要谨慎调参。
