# 位置编码

## 1、绝对位置编码

​		在绝对位置编码中，其本质上是一个和 Attention 输入形状完全相同的向量，是通过计算得到的每个词元的位置信息，然后在 Attention 开始计算 Q、K、V 之前，将位置编码加到输入上，相当于为每个词元的嵌入向量添加了一个与位置相关的偏置，使同一词在不同位置具有不同的表示。

### 经典方法

​		经典方法**（原始 Transformer）**：使用固定公式生成正弦/余弦编码，可外推到比训练更长的序列

*示例：*输入序列 `['我', '爱', '你']`，隐藏维度 `d_model = 4`（实际上通常为 512 或 768，此处简化）

​		得到的词嵌入为：

- `E_我 = [0.1, 0.2, 0.3, 0.4]`

- `E_爱 = [0.5, 0.6, 0.7, 0.8]`

- `E_你 = [0.9, 1.0, 1.1, 1.2]`

  原始 Transformer 的位置编码公式：

  $PE_{(pos,2i)}=sin(\frac{pos}{10000^{2i/d_{model}}}),PE_{(pos,2i+1)}=cos(\frac{pos}{10000^{2i/d_{model}}})$

  其中：

  - `pos`：词元位置（0, 1, 2）
  - `i`：维度索引（0 ≤ `i` < `d_model/2`，即本例中 `i=0,1`）

#### **计算每个位置的PE**：

1. `pos` 0（"我"）：

    - `i=0`（第0、1维度）：

        $PE_{(0,0)}=sin⁡(\frac{0}{10000^{0/4}})=sin⁡(0)=0.0$

        $PE_{(0,1)}=cos⁡(\frac{0}{10000^{0/4}})=cos⁡(0)=1.0$

    - `i=1`（第2、3维度）：

        $PE_{(0,2)}=sin⁡(\frac{0}{10000^{2/4}})=sin⁡(0)=0.0$

        $PE_{(0,3)}=cos⁡(\frac{0}{10000^{2/4}})=cos⁡(0)=1.0$

    - 结果：`PE_我 = [0.0, 1.0, 0.0, 1.0]`

2. `pos` 1（"爱"）：

    - `i=0`：

        $PE_{(1,0)}=sin⁡(\frac{1}{10000^{0/4}})=sin⁡(1)\approx0.8415$

        $PE_{(1,1)}=cos⁡(\frac{1}{10000^{0/4}})=cos⁡(1)\approx0.5403$

    - `i=1`：

        $PE_{(1,2)}=sin⁡(\frac{1}{10000^{2/4}})=sin⁡(0.01)\approx0.0100$

        $PE_{(1,3)}=cos(\frac{1}{10000^{2/4}})=cos(0.01)\approx0.9999$

    - 结果：`PE_爱 ≈ [0.8415, 0.5403, 0.0100, 0.9999]`

3. `pos` 2（"你"）：

    - 类似计算得：`PE_你 ≈ [0.9093, -0.4161, 0.0200, 0.9998]`

#### 将所得的 `PE` 加到词嵌入上

​		$X=E+PE$

#### 再输入到 Attention 层

### 可学习的位置编码

- 可学习的位置编码：直接训练一个位置嵌入矩阵 `nn.Embedding(max_len, d_model)`，更灵活但可能受限于训练时的最大长度

​		总结来说，绝对位置编码通过简单的向量加法，将位置信息无缝缝合到注意力计算中，这种设计既高效又易于实现，成为 Transformer 架构的核心组件之一

## 2、相对位置编码

​		在相对位置编码中，位置编码是一个与**注意力分数矩阵**形状相关的张量，尺寸为 `[seq_len, seq_len, d_dim]`，每个元素 `B[i, j]` 表示位置 `i` 和 `j` 之间的相对距离的编码。在 Attention 计算之后、Softmax 之前，将相对位置编码 `B` 直接加到注意力分数矩阵上。不是为词元添加位置偏置，而是直接调整词元间的注意力强度。例如，让模型更关注邻近词（`|i-j|` 小的时候 `B[i, j]` 更大）。

- **可学习的相对位置偏置**：直接训练一个参数矩阵 `B`，其中 `B_{k}` 对应相对距离 `k` 的编码（`k = i-j`）。
- **公式生成**（如 `Transformer-XL`）：通过正弦/余弦函数生成，但基于相对距离而非绝对位置。

## 旋转位置编码（RoPE）

​		是一种巧妙融合绝对和相对位置的编码方式，其核心设计更倾向于**相对位置编码**。我们来用一个形象的比喻和逐步拆解的方式来解释清楚。

​		想象一下，我们有一支多功能的瑞士军刀，它上面有很多小工具（比如小刀、剪刀、螺丝刀）。

*   **`head_dim` (特征维度)**：就好比这把军刀上**所有小工具的总宽度**。假设是128毫米（对应维度为128）
*   **Word Vector (词向量)**：当一个词（比如 "我"）进入模型，它被表示成一个长度为128的向量。这就像我们拿到了一根128毫米长的金属条，准备把它打造成一把军刀。

RoPE (旋转位置编码) 的思想是：我们**不直接在金属条上刻上位置（比如"位置1"）**，而是通过一种更聪明的方式——**旋转**——来赋予它位置感。

---

### （1）成对的二维旋转

​		RoPE并不把128个维度看作128个独立的数字。相反，它把它们**两两一组**，看作是64个独立的**二维坐标系**（或者说复数平面）。

*   维度0和维度1，组成第1个坐标系。
*   维度2和维度3，组成第2个坐标系。
*   ...
*   维度126和维度127，组成第64个坐标系。

现在，我们那根128毫米的金属条，就被看成了64个小小的二维向量 `(x_0, x_1)`, `(x_2, x_3)`, ..., `(x_126, x_127)`。

### （2）不同的旋转角度

​		现在我们有了可以旋转的二维向量，那么**转多少度**呢？这个旋转的角度就由**单词的位置**决定。

*   对于位置为 `m` 的单词，我们在第 `i` 个坐标系里，要把它旋转 `m * θ_i` 角度。

这里的关键是 `θ_i`，它是一个预先设定的**“基础旋转速度”**。这个速度对于不同的坐标系是不同的。

*   **低维坐标系 (i 较小)**: 它的 `θ_i` 比较大，转得快。就像时钟的秒针。
*   **高维坐标系 (i 较大)**: 它的 `θ_i` 比较小，转得慢。就像时钟的时针。

这个 `θ_i` 通常用公式定义：
$$
\theta_i=10000^{-\frac{2i}{d}}
$$

其中 `d` 是总维度（`head_dim`，这里是128），`i` 是坐标系的索引（从0到63）。

### （3）预计算的旋转矩阵

​		在二维坐标系中，要将一个点 `(x, y)` 旋转 `A` 角度，我们需要用到 `cos(A)` 和 `sin(A)`。这就是所谓的旋转矩阵。

​		所以，对于一个在**位置 `m`**、我们需要在**第 `i` 个坐标系**对其进行旋转时，实际的旋转角度是 `m * θ_i`。我们需要的值就是 `cos(m * θ_i)` 和 `sin(m * θ_i)`。

### （4）创建查询表

现在我们把所有东西串起来。模型知道它可能处理的最大序列长度（比如 4096），也知道每个头的维度（比如 128）。

所以，在**模型加载时（而不是在每次处理请求时）**，它会执行以下操作：

1.  创建一个巨大的表格（或者说两个表格，一个给cos，一个给sin）。
2.  这个表格的**行**对应**位置 `m`**（从 0 到 4095）。
3.  表格的**列**对应**维度 `j`**（从 0 到 127）。

4.  它会去填充这个表格：
    *   对于表格的 `[m, j]` 这个单元格：
        *   首先，确定 `j` 属于哪个坐标系，`i = floor(j / 2)`。
        *   然后，计算基础旋转速度 `θ_i`。
        *   最后，计算 `cos(m * θ_i)` 和 `sin(m * θ_i)` 并填入两个表格的对应位置。

​		**最终结果就是两个大矩阵 `cos_table` 和 `sin_table`，形状都是 `(max_seq_len, head_dim)`**。

​		这样做的好处是**极高的效率**。计算 `cos` 和 `sin` 是比较耗时的操作。通过一次性预计算所有可能用到的值并存起来，模型在实际运行时只需要做快速的查表操作，而无需在每次前向传播时都重复进行大量三角函数计算。
