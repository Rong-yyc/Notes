# 学习率

​		学习率（通常记作 $\alpha$ 或 *lr* ）是一个正数，表示每次参数更新时，**梯度对参数调整的影响大小**。
数学表达为：

​		$\theta_{t+1}=\theta_t−\alpha\cdot\nabla_\theta J(\theta_t)$

​	其中：

- $\theta_t$ 是当前模型参数；
- $\nabla_\theta J(\theta_t)$ 是损失函数对参数的梯度；
- $\alpha$ 是学习率。

1、学习率的大小：过大的学习率会导致损失函数剧烈震荡甚至爆炸，无法收敛；过小的学习率会导致训练停滞，可能卡在非最优解（如局部最小值或鞍点[^1]）

2、常见策略：针对大模型训练，学习率通常需要动态调整

- 学习率预热（Warmup）：初期从小学习率开始，逐步增大，避免梯度不稳定（Transformer 模型常用）
- 动态衰减（Decay）：随训练步数增加逐渐降低学习率（如线性衰减、余弦退火）
- 自适应学习率：使用 Adam、Adagrad 等优化器，为不同参数分配不同的学习率

## 余弦退火学习率调度器

1、核心思想

- **周期性退火**：学习率从初始值开始，按余弦函数规律逐渐下降至最低值（可能非零），然后突然**重置回初始值**（或另一个值），形成周期性波动。
- **平滑过渡**：余弦函数的特性使得学习率变化连续且平滑，避免阶梯式衰减（如 Step Decay）的突变。
- **跳出局部最优**：周期性重置学习率可能帮助模型逃离局部极小值。

# 梯度爆炸（Gradient Explosion）

​		梯度爆炸是指**反向传播过程中，梯度值急剧增大**（甚至趋于无穷大），导致参数更新过大，模型无法收敛。

1、原因

- **链式法则**：反向传播时，梯度是各层梯度的乘积。如果每层的梯度 ＞ 1，深层网络的梯度会指数级增长
- **初始化权重不当**：如果初始权重过大（如全设为1.0），前向传播的输出和反向传播的梯度都会放大
- **激活函数的选择**：使用梯度容易放大的激活函数（如ReLU在正区间导数为1，无饱和机制）
- **学习率过高**：过大的学习率会放大梯度更新的幅度，加剧不稳定性

2、表现：训练过程中损失值突然变为 `NAN`；模型参数出现异常大的数值；训练完全无法收敛

3、解决方案：梯度裁剪、降低学习率或使用学习率预热、调整激活函数、批量归一化、残差连接

## 梯度裁剪（Gradient Clipping）

​		通过限制梯度的最大值或范数，防止梯度爆炸导致的数值不稳定

1、按值裁剪：例如，设置 `threshold=1.0`，所有梯度值被限制在 [−1.0, 1.0] 之间。

2、按范数裁剪：计算梯度的 L2 范数[^2]，如果超过阈值，则按比例缩放梯度。例如，`max_norm=5.0`，如果梯度范数超过5，则等比例缩小梯度。

[^2]: 也称为**欧几里得范数**，是衡量向量（或张量）大小的一种方式，表示向量在空间中的“几何长度”，即所有分量的平方和再开平方根。
