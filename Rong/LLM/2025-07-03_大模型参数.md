# 参数类型

​		在整个大模型的训练和推理过程中，参数类型主要分为四类：模型参数和超参数

- 模型参数：模型通过训练自动学习的参数，直接参与前向传播和反向传播，是模型的核心组成部分
- 超参数：人为设定的参数，用来控制模型的结构和训练过程，不通过训练学习
- 冻结/共享/量化参数：用于优化效率或者迁移学习
- 临时参数：在训练或推理中动态生成的参数，不持久保存

## 模型参数

### 权重矩阵（Weight Matrices）

​		通常初始化为随机值，训练时通过梯度下降更新

### 偏置项（Bias Terms）

​		在某些场景下可以省略

### 嵌入矩阵（Embedding Matrix）

​		是用来将 token 映射为指定长度向量的矩阵，参数量大，<font color="red">通常占模型总参数量的显著部分</font>

## 超参数

### 结构超参数

​		如模型层数（`num_layers / num_hidden_layers`）、隐藏层大小（`hidden_size`）、注意力透数（`num_heads`），这些参数直接决定模型容量和计算效率

### 优化超参数

​		学习率（`learning_rate`）、批量大小（`batch_size`）、Dropout 率（`dropout_p`）、梯度裁剪阈值（`grad_clip / clip_norm`）、权重衰减（`weight_decay`）等，这些参数决定模型收敛速度和最终性能

## 冻结/共享/量化参数

​		冻结参数指的是在迁移学习或微调阶段，固定某部分参数不参与更新，通常用于保留预训练知识

​		共享参数指的是同一参数被多个模块复用，减少模型体积

​		量化参数指的是在模型压缩阶段引入的参数，用于低精度表示

## 临时参数

​		在训练或推理过程中动态生成的参数，不持久化保存

# 参数数据类型

<font color="honydew">注：这里的参数指的是模型参数，不包括超参数等其他参数类型</font>

| **类型**  | **精度** | **显存占用** | **训练稳定性** | **典型场景**              |
| :-------- | :------- | :----------- | :------------- | :------------------------ |
| FP32      | 高       | 大（4B/参）  | 最优           | 训练默认                  |
| BF16      | 中       | 中（2B/参）  | 高             | 大模型训练（如 PaLM）     |
| FP16      | 低       | 中（2B/参）  | 需梯度缩放     | 混合精度训练              |
| INT8/INT4 | 极低     | 小（1B/参）  | 不适用         | 推理量化（如 LLM.int8()） |

## 权重矩阵

​		常见数据类型：FP32（float32）、FP16（float16）/ BF16（bfloat16）、INT8 / INT4

- FP32：在训练时广泛使用，提供高精度，避免数值溢出/下溢[^1]
  - 缺点：占用内存大，每个参数 4 个字节，计算速度慢
- FP16 / BF16：混合精度训练
  - FP16 节省内存和计算资源，但容易梯度下溢（范围小），谷歌提出 BF16，保留更多指数位，解决 FP16 的范围问题（适合大模型）
- INT8 / INT4：推理量化，通过量化技术将 FP32 权重压缩为低精度整数，减少显存占用
  - 缺点：需校准和缩放因子

**训练阶段：**FP32（稳定）或 BF16 / FP16（加速 + 显存优化）

**推理阶段：**FP16 / BF16 或 INT8 / INT4（量化部署）

## 偏置

​		通常和对应的权重矩阵同类型，某些框架允许偏置保持 FP16，即使权重是 INT8 类型

### Q&A

1、为何允许偏置保持 FP16，权重量化为 INT8 类型？

答：因为偏置通常为接近 0 的小值，FP16 可以精确表示，而 INT8 缩放后可能丢失信息；此外偏置的微小变化可能显著影响输出（尤其是深度网络），需要更高精度

## 嵌入矩阵

​		常见数据类型：FP32 / FP16 / BF16，默认与模型其他参数一致，FP16 可能引发词嵌入稀疏区的数值下溢

​		只有在推理的时候才会谨慎的使用 INT8 类型，因为嵌入矩阵的离散性可能导致显著精度损失

​		某些框架允许嵌入层保持 FP32，其他层用 FP16（避免词向量质量下降）

[^1]: 数值溢出指的就是数值的绝对值超过数据类型能表示的最大值，当数值的绝对值小于数据类型能表示的最小正值时，发生下溢。FP16 能表示的最小正值约为 $5.96e^{-8}$，若计算 $1e^{-9}$，可能就直接变为0了
