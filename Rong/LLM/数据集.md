# 大模型的训练

​		大模型的训练流程通常分为三个阶段：

- 预训练：在海量无标注数据上训练模型（学习语言统计规律）
- 监督微调：用高质量标注数据调整模型行为
- 强化学习微调（可选）：进一步通过人类反馈优化输出

## 监督微调（Supervised Fine-Tuning, SFT）数据集

​		在预训练模型的基础上，通过监督学习对模型进行任务特定的微调，核心目标是：

- 对齐模型行为：让模型的输出更符合人类意图或特定任务需求
- 提升可控性：通过标注数据明确指导模型“应该怎么回答”，而非仅依赖预训练时的统计模式

​		**SFT数据集**是用于监督微调的标注数据，其核心特点是：

- **输入-输出对**：每个样本包含一个输入（如用户指令）和对应的**理想输出**（由人类或专家提供）。
- **高质量、小规模**：相比预训练数据（TB级），SFT数据通常较小（万到百万级样本），但质量要求极高。

#### **常见SFT数据集示例**

| 数据类型 | 输入示例                                    | 输出示例                                                     |
| :------- | :------------------------------------------ | :----------------------------------------------------------- |
| 指令遵循 | "写一首关于春天的诗"                        | "春风拂面百花开，柳絮轻扬燕归来…"                            |
| 问答对   | "地球半径是多少？"                          | "平均半径约6371公里。"                                       |
| 多轮对话 | 用户："推荐一部科幻电影" AI："《星际穿越》" | 用户："为什么推荐它？" AI："因为它的科学细节严谨且情感深刻。" |

## 基于人类反馈的强化学习（Reinforcement Learning from Human Feedback，RLHF）数据集

​		RLHF数据集不直接提供“标准答案”，而是通过**人类对模型输出的排序或评分**来间接指导模型学习更符合人类价值观的响应

- **不是输入-输出对**，而是**同一输入对应的多个模型输出+人类排序/评分**。
  **示例**（文本生成任务）：
  - **输入（Prompt）**: "解释相对论的基本概念"
  - **输出A（模型生成）**: "相对论是爱因斯坦提出的，分为狭义和广义。"
  - **输出B（模型生成）**: "相对论描述了时空和引力的关系，E=mc²是著名公式。"
  - **人类标注**: 输出B ≻ 输出A（B优于A）

​		一般来说比 `SFT` 数据集更小，但是成本极高。通常会与 `SFT` 结合，`SFT` 提供基础任务能力（“学会回答”），`RLHF` 优化回答质量（“回答的更好”）
